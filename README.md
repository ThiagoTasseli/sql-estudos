# 🧠 Estudos de SQL - Thiago Tasseli

Repositório com consultas SQL separadas por tema e comando principal.

## 📂 Estrutura
- **01-basico/** → SELECT, WHERE, IN, BETWEEN, LIKE, ORDER BY, LIMIT, etc.

Cada arquivo contém uma consulta com foco em um comando SQL específico.

## 🧩 Exemplo
```sql
-- Exemplo do arquivo where_between.sql
SELECT *
FROM filme
WHERE duracao_min BETWEEN 50 AND 200;
```

## 💻 Banco usado
> PostgreSQL (compatível com MySQL e SQLite)
